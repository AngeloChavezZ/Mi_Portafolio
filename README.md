# 💼 Portafolio Personal - Angelo Chávez

Portafolio web donde presento mi perfil como desarrollador junior, mis habilidades y mis proyectos.

🔗 **Verlo en vivo:** [angelochavezz.github.io/Mi_Portafolio](https://angelochavezz.github.io/Mi_Portafolio/)

## 🧰 Tecnologías

- HTML5
- CSS3
- Diseño responsive (adaptable a movil y escritorio)
- Publicado con GitHub Pages

## 📄 Secciones

- **Sobre mi** - mi perfil y enfoque como desarrollador
- **Habilidades** - las tecnologías con la que trabajo
- **Proyectos** - mis proyectos destacados, con enlacea su código
- **Contacto** - Linkedin, GitHub y correo

## 💻 Cómo verlo localmente

1. Clona el repositorio:
```bash
    git clone https://github.com/AngeloChavezZ/Mi_Portafolio.git
``` 
2. Abre el archivo `index.html` en tu navegador.
